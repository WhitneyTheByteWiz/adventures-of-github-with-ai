# src/ — Code Organization

This folder keeps all the code for the page together:

│ src/
│ ├── index.html   ← the page markup
│ ├── css/
│ │   └── style.css
│ ├── js/
│ │   └── main.js
│ └── README.md    ← (this file)

## Notes
- `index.html` references `css/style.css` and `js/main.js` with relative paths, so open `src/index.html` directly **or** serve `src/` to see the styled page.
- This is a learning repo: experiment with branches and pull requests to evolve these files.
